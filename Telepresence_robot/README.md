# Remote-Controlled Telepresence Robot

## Overview
This university group project involved designing and building a mobile robot capable of remote operation through SSH over the internet. The system was intended to simulate physical presence during situations where in-person attendance was not possible.

## Features
- SSH-based remote control
- Internet connectivity for long-distance operation
- Motorized base with directional control
- Telescopic structure for adjustable height
- Camera mount for remote visual feedback

## Technologies Used
- Linux-based control system
- SSH remote command execution
- DC motors and motor drivers
- Custom mechanical design

## Learning Outcomes
- Network-based robot control
- Mechanical design for stability and mobility
- Integration of electronics and software for remote operation
