# SolidWorks Prototyping – Nerf Mechanism

## Overview
This project consists of a full 3D redesign of a Nerf-style toy mechanism using SolidWorks. The goal was to practice CAD modeling, assembly creation, and mechanical visualization.

## Work Completed
- Modeling of internal firing mechanism components
- Design of external housing and ergonomic features
- Creation of assemblies and exploded views
- Application of parametric modeling techniques

## Skills Demonstrated
- SolidWorks part and assembly design
- Mechanical component modeling
- CAD organization and documentation
