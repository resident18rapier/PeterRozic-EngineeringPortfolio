# Automotive Diagnostics – Antis SRL

## Overview
This project contains photographic evidence and technical analysis performed during my role as Warranty Advisor at Antis SRL. I inspected and diagnosed mechanical and electrical failures in vehicles from multiple brands.

## Responsibilities
- Visual and functional inspection of components
- Use of diagnostic tools (scanner, multimeter, oscilloscope)
- Identification of root causes (wear, misuse, manufacturing defects)
- Preparation of technical reports for warranty approval
- Recovery of previously unclaimed warranty cases

## Types of Failures Documented
- Spark plug carbonization
- Ignition coil thermal damage
- Clutch disc glazing and wear
- ABS sensor contamination
- Steering system leaks
- Electrical connector corrosion
- Fuel pumps malfunction
- CMP sensor problem

## Skills Demonstrated
- Automotive diagnostics
- Technical reporting
- Failure analysis
- Warranty management
