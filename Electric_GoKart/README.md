# Electric Go-Kart Project

## Overview
This project documents the complete development of an electric go-kart built according to FIA competition chassis dimensions. It includes mechanical design, structural analysis, electrical integration, battery testing, and GUI development.

## Key Objectives
- Design a competition-grade chassis using SolidWorks.
- Perform Von Mises stress analysis and frontal collision simulations.
- Integrate a 60V, 2500W BLDC motor and transmission system.
- Implement a lithium battery pack and perform discharge testing.
- Develop a graphical interface to display speed and battery percentage.
- Validate performance through real circuit testing.

## Tools & Technologies
- SolidWorks (3D modeling, FEA)
- Python (GUI development)
- Raspberry Pi (embedded system)
- Electrical diagnostics tools (multimeter, oscilloscope)

## Results
- Fully functional electric go-kart capable of circuit operation.
- Structural validation through simulation.
- Battery discharge curves and autonomy analysis.
- Complete documentation including CAD models and testing procedures.
